# 02 - Soluciones

| Problema | Solucion | Resultado |
| --- | --- | --- |
| SQL Injection | Eloquent Query Builder y validacion | Consultas parametrizadas |
| XSS | React escaping e Inertia props | Salida segura por defecto |
| Validacion debil | Form Requests | Reglas centralizadas |
| N+1 Query | Eager loading `with('source')` | Menos consultas |
| Acoplamiento | Controller + Service + Repository | Codigo mantenible |
| Sin IA | `LeadAiAnalyzerContract` | Proveedor intercambiable |
| Sin pruebas | Pest Feature/Unit tests | Mayor confianza |
| Sin deploy claro | Guia Railway/Render/Hostinger/VPS | Operacion simple |
